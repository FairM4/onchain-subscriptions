OnchainSubscriptions – Recurring Crypto Payment Contract
OnchainSubscriptions enables service providers to charge recurring subscription fees directly on-chain.
Users approve billing upfront, and payments are automatically processed per cycle.

Core Capabilities
- Create subscription plans with custom pricing and billing cycles
- Users opt-in and authorize recurring charges
- Auto-charge mechanism triggered by scheduled execution
- Service pause/cancel functions for both users and providers
- Secure allowance enforcement and grace period management

Key Functions
create-plan, subscribe, charge, cancel-subscription, get-plan, get-user-status
